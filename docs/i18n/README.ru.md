# Руководство по мультиязычной поддержке CLI

В этом документе описывается объем мультиязычной поддержки в текущем CLI,
способы переключения языков и способы добавления переводов.

## Поддерживаемые в настоящее время языки

- Английский: `en`
- Упрощенный китайский: `zh-CN`
- Традиционный китайский: `zh-TW`
- Французский: `fr`
- Японский: `ja`
- Немецкий: `de`
- Корейский: `ko`
- Испанский: `es`
- Русский: `ru`

### Пояснение

- `zh-TW` основан на автоматическом преобразовании упрощенного китайского в
  традиционный с ручной доработкой. Рекомендуется проверять формулировки и тон
  на соответствие реальному пользовательскому интерфейсу.
- Если вам нужно добавить новый язык, см. раздел «Как добавить переводы» ниже.

## Как переключить язык

Вы можете выбрать язык интерфейса следующими способами (для вступления в силу
перезапустите CLI):

1. **Файл настроек** Установите в `.gemini/settings.json`:

```json
{
  "general": {
    "language": "ja"
  }
}
```

2. **Переменная окружения**

```bash
export GEMINI_LANG=fr
```

```bash
export GEMINI_LANG=fr
```

3. **Интерактивные настройки**

Запустите команду `gemini settings` (или войдите в интерактивное меню настроек),
перейдите к опции `language`, выберите свой язык и подтвердите. Перезапустите
CLI, чтобы изменения вступили в силу.

4. **Системная локаль**

Если вышеуказанные настройки не заданы, CLI по умолчанию будет использовать
системную локаль (если она поддерживается).

> Если установлено несколько источников, приоритет следующий: Аргументы
> командной строки (если есть) > Переменная окружения > Файл настроек >
> Системная локаль.

## Как добавить переводы

### Переводы уровня CLI (UI и подсказки)

1. Создайте каталог языка в `packages/cli/src/i18n/locales/`, например, `fr`:

```
packages/cli/src/i18n/locales/fr/
  common.json
  commands.json
  errors.json
  auth.json
  tips.json
  keyboard.json
  dialogs.json
  privacy.json
  phrases.json
```

2. Вы можете скопировать английские файлы в качестве шаблона:

```bash
cp -R packages/cli/src/i18n/locales/en packages/cli/src/i18n/locales/fr
```

3. Измените `packages/cli/src/i18n/index.ts`, чтобы сопоставить новые языковые
   ресурсы с реальными JSON-файлами.

### Переводы уровня Core (Логи и низкоуровневые подсказки)

- Core в настоящее время предоставляет файлы перевода:
  `packages/core/src/i18n/locales/zh-CN.json`,
  `packages/core/src/i18n/locales/zh-TW.json`
- Для других языков добавьте соответствующий JSON и зарегистрируйте его в
  `packages/core/src/i18n/index.ts`.

## Примечания по переводу

- Оставляйте ключи без изменений, переводите только значения.
- Оставляйте без изменений заполнители переменных, например, `{{name}}`,
  `{{count}}`.
- Переводы типа массива должны сохранять структуру массива.
